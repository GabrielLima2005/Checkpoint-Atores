# CinePeople — CheckPoint 02

Aplicativo web desenvolvido para o segundo CheckPoint.

## Proposta

Um catálogo estilizado de atores e atrizes, com cards contendo foto, nome, país e data de nascimento.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Array de objetos no `dados.js`

## Requisitos atendidos

- Título
- Renderização de todos os atores e atrizes
- Grid de cards
- Foto
- Nome
- País
- Data de nascimento
- Campo de busca com `input type="text"`
- Evento `oninput`
- `filter()`
- `includes()`

## Estrutura

```text
Checkpoint_Atores_Estilizado/
├── index.html
├── style.css
├── script.js
├── dados.js
└── README.md
```

## Como executar

Abra o arquivo `index.html` no navegador.

## Filtro

O filtro é executado automaticamente enquanto o usuário digita no campo de busca.
